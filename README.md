# Pie Charts with Python and Matplotlib

Python/Matplotlib script drawing pie charts of morphometric proportions, demonstrated on Mariana Trench data. Reusable scientific-plotting example.

## Scripts

- `pie_charts.py`

## Data

- `Tab-Morph.csv`

## Requirements

Python 3 with `matplotlib`, `numpy`, `pandas`.

```
pip install matplotlib numpy pandas
```
